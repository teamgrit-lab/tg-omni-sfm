# Context Runbook (2026-02-20)

This document summarizes the work done in this session so it can be repeated later.

## Goals
- Run 360 video SfM on `data/river_stair.mp4` inside Docker.
- Build a single model (no per-angle splits).
- Use a higher frame interval (24).
- Export PLY from the sparse model.

## Docker Image Assumptions
- Image name used: `omni-sfm-colmap:latest`
- Container has `colmap` and `python3` available.

## Main Pipeline Command (frame_interval=24)
```bash
sudo docker run --rm -v "$(pwd)":/workspace omni-sfm-colmap:latest \
  python3 scripts/run_full_pipeline.py \
  --video_path /workspace/data/river_stair.mp4 \
  --frame_interval 24 \
  --matcher exhaustive
```

## PLY Export Command
```bash
sudo docker run --rm -v "$(pwd)":/workspace omni-sfm-colmap:latest \
  bash -lc "mkdir -p /workspace/outputs/20260205020842/sfm/final_ply && \
  colmap model_converter \
    --input_path /workspace/outputs/20260205020842/sfm/sparse/0 \
    --output_path /workspace/outputs/20260205020842/sfm/final_ply/points3D.ply \
    --output_type PLY"
```

## Notes / Troubleshooting
- If you see an OpenGL context error during feature extraction, keep GPU disabled
  in `scripts/run_full_pipeline.py` (already done in this workspace).
- `project.ini` is created during mapping but not regenerated by `model_converter`.
  If needed, copy from the original sparse model directory.
